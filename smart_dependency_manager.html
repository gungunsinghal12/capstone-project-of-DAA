04 / Algorithm benchmark

Compares Kahn and DFS on generated directed acyclic graphs. Results vary by device and browser.

Kahn's algorithm (BFS)

Hinglish: Jin tasks ki koi pending dependency nahi hoti (in-degree 0), unhe queue mein daalte hain. Queue se task nikaal kar complete mark karte hain aur uske dependent tasks ka in-degree kam karte hain. Jiska in-degree 0 ho jaaye, woh queue mein aa jaata hai. Agar saare tasks process na hon, to cycle present hai.

Complexity: Time O(V + E), space O(V). Parallel rounds har iteration mein saath start ho sakne wale tasks dikhati hain.

Depth-first search (DFS)

Hinglish: DFS har node ko WHITE (unvisited), GRAY (current path) ya BLACK (completed) mark karta hai. Kisi GRAY node par wapas pahunchna back edge hai, jo cycle prove karta hai. DAG mein nodes ko finishing time ke reverse order mein rakhne se topological order milta hai.

Complexity: Time O(V + E), space O(V). Dono algorithms valid DAG ke liye topological order nikaalte hain.
